# Cloneflix Login Page

A simple Netflix-inspired login page built using **React**, **Tailwind CSS**, **Axios**, and **Node.js/Express**.

This project demonstrates how a React frontend communicates with an Express backend through an API for user login.

## Technologies Used

### Frontend
- React
- React Router DOM
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- CORS
